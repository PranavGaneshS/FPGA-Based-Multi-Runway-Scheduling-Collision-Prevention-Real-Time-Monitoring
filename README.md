# FPGA-Based-Multi-Runway-Scheduling-Collision-Prevention-Real-Time-Monitoring
FPGA-based airport runway scheduling system managing 3 runways and 9 flights using Verilog HDL. A FIFO queue and priority-based scheduler dynamically allocate flights while preventing runway conflicts. Each runway uses an FSM and occupancy timer. An LCD provides real-time runway status and flight ID monitoring.
